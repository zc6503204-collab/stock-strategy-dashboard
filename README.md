# 短线＋波段观察台 · 工作台 4.0 / 多策略实验

本机网页：**http://127.0.0.1:8765/**。双击 `start.command` 打开。日常行情、判断、通知和收盘摘要由本机程序完成，不运行Codex周期任务，不调用AI模型；开发或主动要求AI解读仍使用相应额度。行情请求遵守现有订阅和接口限额。

## 双市场工作区

顶部的 **A股工作区 / 美股工作区** 会同时切换决策、盘前名单、持仓、复盘、策略说明、货币、基准和行情时间。页面会记住上次选择，也可以用 `?market=CN` 或 `?market=US` 直接打开。A股采用人民币、沪深300与北京时间；美股采用美元、SPY与美东时间，并同时显示北京时间。两个市场的候选、持仓、提醒和统计不会交叉显示。

## 页面

- **今日决策**：首屏只显示市场状态、一只综合首选、两只备选、真实持仓紧急项和等待原因。突破型与回调型统一排名；没有满足全部条件时明确显示“今天暂不买”。
- **盘前观察**：当前市场按完整日线的趋势、流动性、相对强弱与价格位置生成紧凑名单；点击股票后查看图表和完整依据。“准备度”只用于排序，不是胜率，也不是买入信号。
- **持仓管理**：真实与模拟持仓使用独立标签。可手工登记真实买入，或从长桥CLI、盈透本地只读接口同步多头股票持仓；保护价和止盈价由用户登记，触发时提醒，不自动下单。
- **复盘研究**：分开显示策略影子模拟与组合模拟。影子模拟让每条有效信号独立运行，用于比较策略自身；组合模拟执行资金竞争、同股合并、最多3只持仓和最多1只波段仓位。两种口径均展示成本后收益、胜率95%区间、利润因子、回撤、连续亏损、成交失败、持有时间和成本加倍结果。
- **策略中心**：按日内、短线、波段筛选策略。A股有6种、美股有7种；每张卡显示当前版本、前向影子样本、胜率区间、利润因子、最大回撤和数据要求。A股与美股参数独立保存；修改或恢复历史参数都会生成不可修改的新版本，取消该策略的旧待买信号，已有持仓继续沿用入场版本。
- **单股分析**：输入代码或名称，优先读取本机日线和五分钟K线，逐项显示行情新鲜度、同源基准、14日同时间量能和买卖盘状态。数据未齐时仍显示可靠的趋势与关键位，但不确认买点。可临时填写数量、成本、日期、保护价与目标价；只有明确点击保存后才写入真实持仓，只有点击加入监测后才占用监测名额。分析结果及临时输入只在当前浏览器会话保留。
- **策略说明**：按当前市场说明盘前、开盘区间、买点、执行和退出规则，并单列A股T+1或美股交易差异。
- **系统状态**：集中显示长桥、盈透、灵犀的连接与权限、Mac通知、监测设置和日志。交易页面只显示行情正常、延迟或中断。

## 七种策略与统一规则

共同条件：股票站上且20日均线上行（与5个交易日前的20日均线比较）；20日平均成交额A股至少1亿元，美股至少500万美元；20日收益超过同日期基准。A股基准沪深300（000300.SH），美股SPY，基准不进入选股交易范围。股票与基准的日线日期、行情来源须一致。

突破：A股开盘15分钟、美股开盘5分钟区间收阳；随后完整5分钟收盘由下向上突破区间最高价，并站上当日近似VWAP。当天累计成交量与过去14个交易日同一交易所本地时间累计成交量均值比较，至少1.5倍。基准同期完整5分钟收盘也须高于其近似VWAP。最早确认时间为当地9:50和9:40。

回调：技术突破后6根完整5分钟K线内首次回踩，触及区间为突破位上方0.3%以内且收盘守住；之后完整收盘超过上一根高点并通过同一量价、基准条件才确认。跌破已记录回调低点、收盘失守突破位、超过6根或跨交易日则取消。

趋势回踩再启动：日线收盘高于MA20、MA20高于MA60且均线向上，20日跑赢基准；盘中先回踩VWAP或五分钟EMA20附近并守住，下一根完整K线突破回踩K线高点，确认量不低于此前20根均量的1.2倍。

波动收缩突破：日线MA20向上、距20日高点不超过5%，ATR5/ATR20不超过0.75；盘中完整五分钟K线突破前10个交易日高点、站上VWAP，同时间累计量达到过去14日均值的1.5倍。

趋势RSI回踩：日线位于MA60之上，MA20高于MA60且继续上升；最近5日RSI14曾达到65，当前回落到45—60，价格位于MA20附近且5日均量低于20日均量的80%。盘中回踩VWAP或五分钟EMA20后重新站上，下一根完整K线突破回踩高点且量能达到1.2倍。计划持有1—3个交易日。

VCP波动收缩突破：使用至少260根日线，要求EMA10、EMA20、EMA50多头排列，20日和60日收益均跑赢基准，相对强弱处于本次同市场有效扫描的前30%，高低点抬升且最后5日区间收缩。盘中突破10日整理平台并通过VWAP和14日同时间量能确认。止损采用最后5日整理低点，结构距离超过3倍ATR则取消；计划持有5—10个交易日。

美股20分钟开盘突破：仅适用于美股，以9:30—9:50美东时间形成区间，只接受10:00—11:30之间完整五分钟K线突破。要求站上VWAP、相对成交量至少1.2倍且SPY位于VWAP上方。止损为半个开盘区间，目标为0.75个开盘区间，15:50前强制模拟退出，不隔夜。

每种策略的周期、容差、成交量倍数、信号时限和止损回看范围均在策略中心按市场设置。综合首页只从当前可执行信号中选一只首选和两只备选；同一股票命中多种策略时合并为一个资金计划，同时保留各策略依据。

VWAP按同源5分钟典型价格 `(最高+最低+收盘)/3` 与成交量加权近似。沪深300使用供应商指数活动量作为权重，不将其解释为指数股票成交股数、可执行交易额或可成交价格。

这些是本地实验改版：参考公开研究和开源项目的公开思路，未复制外部业务代码、做空、杠杆或自动下单机制，也不是论文收益复现。排名在通过条件后按当前可执行性、同时间成交活跃度、相对强弱、估计成本负担和前向样本质量排序；历史探索收益不直接决定当天推荐。

## 当前可买与资金检查

推荐必须在信号后的下一根5分钟内，且属于正常交易时段；价格处于触发价至触发价加初始价格风险四分之一之间。报价和接收时间不超过30秒，同源买卖盘查询时间不超过15秒，权限已验证、交易状态正常。盘口时间是本机查询时间，供应商未返回交易所盘口时间时不伪造该时间。超过上限、盘口缺失、停牌、触及涨停、数据缺口或来源切换时不推荐。

同源实时权限依据官方订阅套餐和证券所属交易所核验。Nasdaq套餐不自动代表所有美股交易所完整覆盖；未证实的来源保持待核验。低成交股票最后交易时间较旧只影响当前建议，不单独认定连接故障。

模拟资金人民币、美元各100,000；单笔风险预算0.25%，每市场最多3只持仓、其中最多1只波段持仓，高波动/小盘/ST合计最多1只。不使用杠杆，不摊平亏损。A股和VCP波段策略的数量计算至少使用日线ATR风险距离，并加入估计成本；风险预算不是最大可能亏损。

手续费假设每边0.05%，普通股滑点每边0.10%，高风险每边0.30%。买入计划按已知信号根成交量的1%、当前卖盘数量、现金、手数和风险预算共同限量。A股小盘门槛100亿元、美股20亿美元，ATR/价格至少5%也归为高波动。ST标记需新证券资料验证。

## 模拟与退出

技术信号本身不触发模拟买入。通过现价、盘口和资金检查后保存下一根期间的报价、数量和审批时刻；该根结束后按记录报价加估计滑点、整根实际成交容量复核。模拟数量不能超过当时计划数量；若价格超出本根范围或现金不足则记录未成交。这是保守K线模型，不声称逐笔订单真实成交。整根触及止损与止盈按止损优先，可能把买入前的波动也保守计入。

- 突破型初始止损：信号根及此前3根K线最低价；回调型为确认回调低点。止损不向下放宽。
- 第一止盈：实际模拟买价加两倍初始价格风险。卖出一半，按有效数量取整，不足拆分则全部退出。
- 余仓：首次止盈后随后完整3根K线最低价跟踪，只向上移动，更新从下一根起生效。
- 第三交易日：收盘前10分钟提醒，到期退出；停牌、无成交、跌停或流动性不足时保留敞口并记录原因。
- A股T+1：买入当日触及止损则警示并记录待退出，不能伪造卖出；当日触及止盈只提醒，不承诺次日仍能按该目标卖出。
- VCP波段：达到2倍风险后减半，余仓按随后完整日线的三日低点上移保护，最迟第10个交易日退出。
- 美股20分钟开盘突破：到达固定区间目标时整笔退出；否则15:50美东时间退出，不持仓过夜。
- 触价提醒不等于成交。旧版已有持仓保留旧参数；升级时取消旧待买信号，历史信号和K线不回写。

每条通过执行检查的信号同时进入两个模拟口径：策略影子模拟不占用组合现金、不会与其他策略竞争；组合模拟执行真实的资金、持仓和同股合并约束。历史探索仅使用当时已经完成的数据顺序回放，并明确标注数据范围和固定股票池限制。结束前向样本不足30笔时显示“样本不足”，达到30笔后才允许初步比较，达到100笔后才显示“样本相对稳定”；系统不会按单一胜率自动提高风险。

## 本机盯盘与通知

每个交易日开盘前15分钟准备并自动刷新候选；正常交易时段以推送更新，15秒行情查询补充，收盘后10分钟结束整理。页面分开显示行情时间、本机接收时间、报价年龄、最新完整五分钟K线和实际推送订阅数。按交易日历处理A股午休、美股夏令时与提前收盘；午休保留11:30最后有效数据，不误报连接故障。默认12个监测名额，优先级为真实持仓、模拟持仓、有效买点、手动关注、短线候选、波段候选。持仓和手动关注不会被候选自动挤出；名额已满时明确显示未覆盖对象。

提醒包括新买点、买点失效、止损触及、第一档止盈、跟踪退出、到期退出、持仓数据故障。保护价一般上调仅更新页面。事件按信号/持仓/版本和阶段持久化去重，重启不把旧买点重新发成机会。

通知助手 `.local/ShortlistNotifier.app` 使用系统UserNotifications，状态区分未授权、被拒绝、已提交通知中心和仅看板记录。实际横幅或声音仍受macOS权限、专注模式等控制；“已提交”不表示用户已读。提醒可静音，历史可标已读。

后台登录服务：`~/Library/LaunchAgents/local.shortlist.dashboard.plist`，支持登录后自动启动、崩溃后重启，不依赖网页或Codex保持打开。**Mac休眠、断网、关机或退出登录期间不能保证持续盯盘**；恢复后补齐数据、取消过期计划，不伪造中断期间成交。

## 数据接入与限制

- 长桥：SDK持续连接与分市场权限检查；股票K线和成交量保持同一来源。通过已安装CLI只读同步真实股票持仓。A股、Nasdaq套餐与其他市场权限分开判断。
- 灵犀：A股榜单、报价与手动自然语言筛选补充；不承担已认证的持续主源。
- 盈透：本地IB Gateway/TWS只读行情连接、真实多头股票持仓同步与备用适配，仍须逐标的验证；新版14日基线未验证同源时不切换后继续发信号。
- 同花顺普通客户端：人工核对。

实测长桥按日期历史接口返回配额0（301607），最近1000根K线接口可用。因此使用最近K线逐交易日缓存，能完整匹配14日同时间段才启用量比；美股或缺口股票不足14日时继续等待，并随交易日积累。不采购新数据，不用日线成交量冒充同时间段量比。

当前交易日历验证至2026年底，超出范围暂停新信号。缺少历史风险标记、特殊涨跌停状态或公司行为资料时，不认证A股历史收益回放。仍需盘中前向样本检验断线恢复、实际延迟和策略表现。

## 维护

凭证留在 `.local` 私有目录，只由后台读取，静态服务仅开放 `web/`。所有写接口要求本机来源标记；不实现真实订单接口。数据库保存K线、原始信号、决策变化、模拟交易、通知和收盘报告。升级前备份在 `.local/backups`。

```sh
.venv/bin/python -m pytest -q
node --check web/app.js
```

重新生成本机服务与通知助手：`.venv/bin/python scripts/install_background.py`。助手使用本机Swift编译，临时签名，注册通知需macOS允许；重新安装后核对权限。

策略接口：`GET /api/strategies`、`POST /api/strategies/{id}/config`、`GET /api/strategies/{id}/versions`、`POST /api/strategies/{id}/rollback`、`GET /api/strategies/{id}/recommendations`、`GET /api/strategies/{id}/performance`。单股接口：`POST /api/analyze`、`POST /api/analyze/add-monitoring`。

真实持仓接口：`POST /api/real-holdings/manual`、`POST /api/real-holdings/plan`、`POST /api/real-holdings/remove`、`POST /api/real-holdings/sync`。原候选、模拟、连接与提醒接口兼容保留。
