# SHORTLIST 使用指南

这份指南按每天真正使用的顺序说明操作。系统只提供研究、模拟和提醒；真实买卖由你在券商端决定和执行。

## 1. 安装与启动

需要 macOS、Python 3.10 或更高版本。

```sh
git clone https://github.com/zc6503204-collab/stock-strategy-dashboard.git
cd stock-strategy-dashboard
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./start.command
```

页面地址为 `http://127.0.0.1:8765/`。服务只在本机开放。

如需登录后自动运行和 Mac 通知：

```sh
.venv/bin/python scripts/install_background.py
```

安装后在 macOS“系统设置 → 通知”中检查 SHORTLIST 的通知权限。休眠、关机、断网或退出登录期间无法持续盯盘；恢复后程序会先补齐数据并取消过期计划。

## 2. 连接行情

进入“系统状态”，逐项确认连接、权限和最近数据时间。

### 长桥

长桥承担策略使用的主行情。按照页面提示完成本机 OAuth 授权，再分别确认 A股、美股、K线和盘口权限。App 中可见行情不代表 OpenAPI 具有相同权限。

### 国泰海通灵犀

灵犀用于 A 股全市场策略初筛和补充查询：

```sh
python3 scripts/install_lingxi.py
```

把你自己的 `gtht-entry.json` 放在安装脚本创建的 `.local/vendor/gtht/gtht-skill-shared/`。不要把它复制到 `docs/`、截图、Issue 或提交中。

### 盈透 IBKR

启动 TWS 或 IB Gateway，开启 API 并设置为只读。在“系统状态”中填写本机连接参数并测试。系统只在逐标的权限和数据口径核验通过后，把盈透用于美股核验或备用。

## 3. 每天盘前怎样选股

切换到“A股工作区”或“美股工作区”，进入“盘前观察”。

### A股

点击“重新运行全市场策略筛选”后，程序会：

1. 让灵犀按已启用策略查询 A 股市场。
2. 用长桥补充行业信息和全市场活跃候选，再合并去重。
3. 用榜单补充当日突然活跃的股票；这些补充不会带入下一交易日。
4. 使用长桥同源日线重新计算趋势、流动性、相对强弱、ATR和关键价位。
5. 按准备度和行业软分散取前10只显示。

这不是在旧的119只或某个固定小池子里反复筛选。两个市场每个交易日都会重建核心池；服务盘前未运行时，恢复后会补跑。同行业前两只不扣分，此后每多一只在展示排序中扣4分，但不设置硬上限。刷新失败时不会用空结果覆盖，而是保留最近有效快照并标记“过期”。

### 美股

长桥每天从美股全市场筛选最多80只候选，再用相同的本地日线规则复核和行业软分散。盈透在行情权限验证后承担核验和备用。美股与A股的资金、基准、交易时间和策略参数完全分开。

### 准备度怎么看

准备度只回答“明天或今天盘中值得先看谁”。它不代表买点已经成立，也不是历史胜率。点击候选可以查看：

- 它由哪些策略选入；
- 日线趋势和相对强弱；
- 突破观察位与保护参考；
- 仍缺少的盘中条件。

## 4. 盘中怎样确认

把重点候选点击“加入监测”。默认最多持续监测12只，优先级依次为：

`真实持仓 → 模拟持仓 → 有效买点 → 手工监测 → 短线候选 → 波段候选`

行情推送优先，15秒查询用于补充。候选和监测顺序每5分钟更新；买点必须等待完整5分钟K线。系统会继续检查：

- 股票和基准是否仍在盘中趋势上方；
- 同时间成交量是否达标；
- 行情和盘口是否足够新；
- 当前价格是否已经追高；
- 现金、手数、风险预算和持仓名额是否允许。

只要一项不通过，“今日决策”就显示等待或暂不买。出现可执行信号时，决策卡会同时给出买入区间、不追价上限、止损、第一止盈、数量、占用资金、计划风险和失效时间。

## 5. 单股分析

进入“单股分析”，输入股票名称或标准代码，例如：

- `600206.SH`
- `300750.SZ`
- `AAPL.US`

默认分析是一次即时快照，不占监测名额。页面会列出日线数量、今日完整5分钟K线、历史同时间样本、基准和盘口状态，再逐策略说明“符合、等待或不适用”。数据不完整时仍显示可可靠计算的趋势和关键位，但不会给出买入结论。

点击“加入盘中监测”后才会持续刷新。临时填写成本和数量不会写入数据库；只有点击“保存为真实持仓”才进入持仓管理。

## 6. 真实持仓怎样盯盘

真实成交后进入“持仓管理”，选择手工录入或只读同步。至少核对：

- 股票代码、成交数量和实际成本；
- 买入日期；
- 初始保护价；
- 第一止盈参考。

首页只显示需要立即处理的持仓。完整列表在持仓页，真实与模拟仓位分开。A股当日新买股份即使触及止损，也只记录“T+1暂时无法卖出”，不会伪造成交。

提醒表示条件已触发，不等于券商已经成交。跳空、停牌、涨跌停和流动性不足时，止损价可能无法成交。

## 7. 策略参数与复盘

“策略中心”按日内、短线和波段展示策略。A股与美股参数独立保存。每次修改都会生成新版本：

- 旧版未成交信号取消；
- 已有持仓继续使用入场时的规则；
- 新版前向样本从零开始；
- 历史版本可以回滚，但回滚也会生成一个新版本。

“复盘研究”提供三种口径：

1. **策略影子模拟**：每条有效信号独立模拟，用于看策略本身。
2. **组合模拟**：执行资金竞争、同股合并和持仓上限，用于看实际组合效果。
3. **历史探索**：按当时可见数据回放，用于发现问题，不能当成未来收益保证。

结束的前向交易不足30笔时只显示“样本不足”；达到30笔后才适合初步比较，达到100笔才标记“样本相对稳定”。

## 8. 数据多久更新一次

| 内容 | 默认频率 |
|---|---|
| A股、美股每日核心池 | 每个交易日盘前一次，也可手工强制重跑 |
| 当天异动补充和监测顺序 | 交易时段每5分钟，仅当天有效 |
| 重点股票行情 | 推送优先，15秒查询补充 |
| 买点确认 | 每根完整5分钟K线结束后 |
| 止损、止盈触价 | 有效实时行情到达时 |
| 收盘摘要 | 收盘后10分钟 |

同一交易日已取得的完整日线会复用本机缓存，但所有评分会重新计算。低成交股票最后成交时间较旧，不会单凭这一点判断连接故障。

## 9. 常见问题

### 怎样使用 GPT 选股工作台

打开“GPT 选股”后按四步完成：先选择自动、盘前、盘中或单股模式；生成并预览研究任务；复制到 ChatGPT，在 ChatGPT 内确认 `@longbridge` 调用；最后把整段答案粘回看板。本地附带的最多20只量化候选只是 Longbridge 工具不可用时的后备，不是全市场扫描结果。GPT最终可以选择本地池外股票，但只能返回0–3只。

答案末尾必须包含 `SHORTLIST_RESULT_V1` 结构化 JSON。看板只解析这个标记内的数据，不执行回答中的HTML、链接、脚本或操作指令。字段、市场、交易日、研究包、时间或股票代码不一致时会显示“需要修正”，原文仍留在输入框中，但不会激活候选。

合法导入后，本机会重新读取证券名称、行情、日线与盘口。GPT说“买”仍可能显示“GPT精选·等确认”；只有本地实时价格、盘口、有效信号、不追价线、失效线、风险名额和A股限制全部通过，才会显示“当前可考虑买入”。GPT与本地仓位上限取较小值。收盘后本轮失效，完整问答和账户上下文会清除。

本功能不调用 OpenAI API，也不能后台读取你在 ChatGPT 内连接的 App。账户选项每次默认关闭；只有当次主动勾选，才会把长桥和盈透的脱敏摘要及最多40只持仓写入任务。可选的研究对话链接只接受 `https://chatgpt.com` 地址并保存在本机。平台不会猜测 App 连接状态，也不会提供下单、改单、撤单或最大可买量工具。

### 页面能打开，但没有买入股票

先看“现在为什么不买”。常见原因是休市、盘口缺失、报价过期、14日同时间成交量未预热、基准不同步、已经追高或风险名额已满。系统允许没有推荐，不会为了填满卡片而把观察股包装成买点。

### 单股分析显示部分数据

“部分数据”通常表示已有日线或K线，但还缺基准、盘口或同时间量能。趋势判断仍可展示；严格买点会被统一风控否决。加入监测后程序会继续预热。

### 盘前显示很多初筛股票，最后只有10只

前面的数字是各入口找到并去重后的候选规模；深度核验会淘汰趋势、流动性、相对强弱或数据不完整的股票。页面只展示准备度最高的10只，盘中最多持续盯12只。

### 浏览器关掉后还会提醒吗

安装后台服务后会。浏览器只是界面；本机行情和提醒服务独立运行。Mac进入休眠或断网时无法继续。

### 日常盯盘是否消耗 Codex 额度

不消耗。日常计算和通知由本机规则引擎完成。只有你主动让 AI 研究、解释或修改策略时，才会使用相应服务额度。
